Design Tool / MCP Best Use Case Tradeoff for Lean Startup Recommendation

design/brand/build.mjs (Active now)
 Exact 64u/1024u Bézier control, instant .icns + 12 tray PNG generation, enforced by cargo test --lib brand. Code-first coordinates rather than drag-handles. Keep as canonical source of truth
Figma Official Dev Mode MCP
http://127.0.0.1:3845/mcp (Figma Desktop)
 You tweak curves, App Store screenshots, or OG social cards visually in Figma; Copilot reads live vector nodes & tokens directly. Requires Figma Desktop open locally; read-focused. #1 MCP to enable if you sketch in Figma
Penpot Official MCP Server
Open-source native SVG design canvas
 100% open-source, native SVG/CSS standard storage, two-way token & component inspection without Figma seat lock-in. Smaller community template ecosystem than Figma. Best free/open-source alternative
Recraft Vector MCP
@recraft-ai/mcp-recraft-server
 Generating exploratory SVG illustrations or marketing spot graphics from text prompts. AI-traced paths are noisy for 18px macOS menu-bar masks; paid API credits. Skip for core brand marks
